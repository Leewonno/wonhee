직캠 버튼, 메인 화면 어디에 둘까

실제 메인 화면 크기(데스크톱 1440×900, 휴대폰 390×844)로 그린 뒤 줄여 보여 줍니다. 새 버튼을 누르면 직캠 모달 시안(fancam-modal.html)으로 넘어갑니다. 직캠 수·날짜는 예시 값입니다.

1둥근 버튼 줄에 하나 더

갤러리 버튼 바로 옆에 같은 크기의 직캠 버튼을 둡니다. "사진 보기 · 영상 보기"가 나란히 붙어서 무엇을 보는 버튼인지 묶여 읽힙니다. 데스크톱은 마우스를 올리면 "직캠" 말풍선이 뜹니다.

  • 지금 화면 규칙을 하나도 안 바꿈
  • 구현이 가장 쉬움
  • 아이콘만이라 처음엔 뭔지 모를 수 있음
  • 휴대폰에서 MV 버튼 폭이 줄어듦

2소개 줄 아래 글자 메뉴

"ILLIT · WONHEE · 2007.06.26" 밑에 사진 · 직캠을 밑줄 글자로 둡니다. 갤러리 아이콘 버튼도 여기로 옮겨, 오른쪽 아래는 멈춤과 MV만 남깁니다. 옆에 작은 숫자로 몇 개 있는지 보여 줍니다.

  • 글자라서 바로 뭔지 알 수 있음
  • 사인 · 소개 · 메뉴가 한 덩어리로 읽힘
  • 갤러리 버튼 자리도 같이 바뀜
  • 사인 영역이 한 줄만큼 위로 올라감

3오른쪽 위 구석에 알약 버튼

지금 비어 있는 오른쪽 위에 "직캠 25" 알약 버튼 하나만 둡니다. 아래쪽 버튼들과 겹치지 않고, 휴대폰에서도 엄지가 닿는 아래쪽을 그대로 비워 둡니다.

  • 빈 자리를 쓰니 기존 배치를 안 건드림
  • 글자가 있어 알아보기 쉬움
  • 버튼이 위아래로 흩어짐
  • 사진 위쪽 얼굴 근처에 겹칠 수 있음

4MV 버튼 위 미리보기 카드

최신 직캠 썸네일이 3초마다 바뀌는 작은 카드를 MV 버튼 위에 얹습니다. 무엇이 들어 있는지 버튼이 직접 보여 줍니다. 휴대폰은 아래쪽에 자리가 없어서 오른쪽 위로 올립니다.

  • 눌러 보고 싶게 만듦 (새 무대가 올라오면 바로 보임)
  • 사진 위에 사진이 하나 더 생겨 화면이 붐빔
  • 데스크톱/휴대폰 자리가 달라짐

5MV 버튼을 두 칸으로 나누기

MV 알약을 가운데 선으로 나눠 오른쪽 칸을 직캠으로 씁니다. 영상 두 종류가 한 버튼에 같이 있어 "보러 가는 곳"이 한 군데로 모입니다.

  • 버튼 수가 늘지 않음
  • 글자 라벨이라 알아보기 쉬움
  • MV 버튼이 길어짐
  • 신곡이 바뀔 때마다 둘을 같이 손봐야 함
